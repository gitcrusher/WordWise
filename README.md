
# Music Playlist Music Player

A Flutter application for playing music with playlist management and word learning features.

## Project Structure

```
lib/
├── main.dart                 # App entry point
├── splash_screen.dart        # Initial splash screen
├── welcome_splash_screen.dart # Welcome screen
├── loading_screen.dart       # Loading state UI
├── home_page.dart            # Main home page
├── search_page.dart          # Search functionality
├── onboarding_screen.dart    # User onboarding
├── wordmeaning.dart          # Word definition feature
├── tenwords.dart             # Ten words daily challenge
├── upoad_trie.dart           # Trie data structure upload
├── secret.dart               # Secret features/config
├── intro_screen/             # Intro tutorial screens
│   ├── intro_page1.dart
│   ├── intro_page2.dart
│   └── intro_page3.dart
└── models/                   # Data models
    └── trie.dart             # Trie implementation
```

## Features

- Word learning with definitions
- Daily word challenges
- Onboarding and intro tutorials
- Trie-based data structure for efficient word lookup

## Getting Started

1. Install Flutter SDK
2. Run `flutter pub get`
3. Execute `flutter run`
